# EmoTra-Notepad
EmoTra Notepad is a sentiment-aware journaling app built with Electron and a FastAPI backend. It analyzes your writing in real time to visualize emotional breakdown—Joy, Sadness, Anger, and Anxiety. Features include multi-user login, media attachments, custom wallpapers, entry history management, and cross-platform support.
